# 我的博客

登录页 `/login`，注册页 `/register`，首页底部导航提供退出登录入口。
默认入口为 `/login`，首页和文章页需要登录。登录成功进入首页或原目标页，退出后回到登录页；登录和注册之间有平滑过渡，支持减少动态效果设置。
前端 `npm run dev` 默认运行于 `http://localhost:8082`；Vite 将 `/api` 代理到 `http://localhost:3000`，请同时启动相邻的 `my-blob-api` 项目。
生产部署需要将 `/api` 反向代理到后端，并通过 HTTPS 提供服务。

### AI 工作台

登录后点击底部 Dock 的 Claude 图标进入 `/chat`。页面采用 ChatGPT 风格的侧栏与聊天布局，支持会话搜索与切换、历史分页、多轮流式回复、停止生成、Markdown 与代码高亮、复制代码/回复、Markdown 导出和明暗主题。会话保存在后端；前端不保存聊天正文。`/chat?c=<会话 UUID>` 可恢复指定会话，登录过期后重新登录会返回原页面。

接入相邻 `my-blob-api` 的 `/api/conversations` 和 `/:id/messages/stream`，复用登录令牌。请启动后端并配置其 `AI_*` 环境变量。当前仅支持文本输入，页面没有附件、语音输入和会话删除入口。

AI 回复下方的喇叭按钮支持朗读，朗读中变为停止按钮，可随时点击关闭。朗读其他回复、切换会话、重新加载历史或离开聊天页面会停止当前朗读；读完后自动恢复喇叭图标。使用浏览器 Web Speech API，按内容选择中文或英文语音，过滤 Markdown 标记并分段朗读长回复，不需要后端语音接口。可用声音取决于浏览器和系统的语音设置。

发送按钮左侧的胶囊按钮显示当前模型，悬停轻微放大并提示思考强度，点击打开思考强度面板；点击面板中的模型名称进入模型列表，支持默认模型与单独选择。模型和可用档位来自 `GET /api/conversations/models`，不显示后端未配置的模型。选择会按账号保存在 sessionStorage，并作用于下一条消息；切换模型保留当前会话上下文，不支持的档位自动恢复默认。最高 `max` 档位显示为 **Ultra**，使用蓝紫渐变滑杆；兼容暗黑模式与键盘操作。生成期间关闭设置，回复标题统一显示 AI 助手，模型和思考档位仍随消息保存在后端。

侧栏收起后保留 52px 快捷图标栏，支持新对话、搜索和头像入口。点击顶部图标或按 `Ctrl + Shift + S`（macOS 为 `Cmd + Shift + S`）展开/收起，使用 GSAP 平滑过渡，并遵循减少动态效果设置。手机端展开为覆盖式侧栏。

聊天区和侧栏采用细窄圆角滚动条。会话里的向下箭头平滑滚动至最新消息，手动滚动可中断；减少动态效果模式下直接定位到底部。

验证：`npm test` 检查认证和 SSE 协议；启动前端后运行 `npm run test:chat-ui`，使用本机 Chrome 和模拟接口检查完整交互，不请求真实模型、不创建真实账号。截图保存在 `.artifacts/chat/`。

朗读验证：`npm test` 包含朗读分段、停止、切换、完成与错误回归；启动前端后运行 `npm run test:speech-ui`，使用模拟语音检查按钮切换、键盘操作、离开页面清理和明暗/移动端布局，截图保存在 `.artifacts/speech/`。

### 个人资料

点击底部 Dock 头像进入 `/profile`，支持明暗主题、头像更换与预览，以及昵称、邮箱、所在地、网站、简介编辑。用户名只读；保存期间禁止重复提交，离开未保存页面会提示。头像原图最大 2 MB，前端裁剪缩小到 256×256 后上传。

个人资料统一维护手机号、关于、技术栈与工作经历。所在地使用省份／城市（直辖市为区县）联动选择，保留旧资料值直到主动修改；省份可单独保存，也可清空。地区数据来自 [Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China) 的 `dist/pc.json`，许可证保存在 `src/assets/regions.LICENSE`，选择列表在本地加载。

首页姓名下方展示个人简介，联系方式展示邮箱、所在地、手机号和网站；关于、技术标签与工作经历都读取已保存资料，空内容不展示。技术栈支持回车添加、移除，最多 30 项；工作经历支持增删与排序，最多 20 段，结束月份留空表示至今，工作内容在首页点击公司名称展开，以纯文本展示。

启动前端后运行 `npm run test:profile-ui`，使用模拟账号接口验证编辑、所在地联动、排序、保存失败重试、取消修改、首页展示、刷新恢复和明暗／移动端布局；截图保存在 `.artifacts/profile/`。

通过 `PATCH /api/users/me` 保存到相邻 `my-blob-api` 的 PostgreSQL 数据库，登录和 `GET /api/users/me` 恢复资料；资料以数据库返回内容为准。邮箱冲突和网络错误保留编辑内容，登录过期后回到登录页。`npm test` 包含资料保存、会话隔离和暗黑样式编译回归测试。

成功登录后，公开用户资料缓存到 `sessionStorage.userInfo`（JSON 对象），页面通过 `@/lib/auth` 导出的响应式 `userInfo` 读取。首页名称、头像及聊天侧栏名称、头像统一使用此数据；名称优先显示昵称 `name`，为空时使用账号 `username`。资料编辑成功、会话校验后同步更新缓存，退出或登录过期时清除。刷新可恢复缓存，但路由权限仍由后端会话校验决定。缓存仅包含公开资料，不包含密码或令牌。

用户名为 3–32 位字母、数字或下划线，注册密码为 8–128 位且包含字母、数字；注册还需填写邮箱与确认密码。
登录成功后在 localStorage 的 `myblob_token` 中缓存令牌，接口请求通过 `Authorization: Bearer <token>` 认证，有效期一天。退出立即清除本地令牌并请求后端注销；密码不会保存到浏览器存储。令牌过期会自动清除，跨标签页退出会同步回到登录页。
