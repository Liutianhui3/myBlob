# 聊天生成 Excel 文件

部署时需要同时更新 `myBlob` 前端和 `my-blob-api` 后端，并重启后端。无需数据库迁移。

可以发送：`帮我生成一个可下载的 Excel，包含姓名、部门、工资三列，给出五行示例数据。`

后端系统提示词要求模型在 `xlsx` 代码围栏中返回以下 JSON，前端在围栏完整且数据校验通过后显示文件下载卡片：

````markdown
```xlsx
{"filename":"工资表.xlsx","sheets":[{"name":"工资","rows":[["姓名","部门","工资"],["张三","研发",10000]]}]}
```
````

浏览器按需加载 ExcelJS，点击下载时本地生成真正的 `.xlsx` 文件。无需执行模型返回的代码或额外文件存储服务。JSON 保存在原聊天正文中，重新打开历史会话仍可下载。支持多工作表、数字、文本、布尔值与空单元格；首行加粗并冻结。以 `=` 开头的字符串也按文本保存，不执行公式。

当前仅支持 Excel 数据表，不支持运行任意 Python/JavaScript、图表、公式或 Word/PDF 文件。每个文件最多 20 张表、100000 个单元格；每表最多 10000 行，每行最多 256 列。非法或未完成的数据保留原始代码显示；生成失败可重试下载。模型输出仍受服务端 token 上限限制，大表应拆分请求；模型未遵循格式时可要求其重新生成可下载的 Excel。
